# 13 Weeks of Franklin

A simple 13-week daily habit tracker inspired by Benjamin Franklin.

## Features

- Shows the current date automatically.
- Starts a 13-week journey from the first day you open the site.
- Changes to one Franklin quotation every 7 days.
- Lets you mark each day complete.
- Saves progress automatically in your browser with `localStorage`.
- Shows weekly and total progress.
- Works on desktop and mobile.
- No database or backend required.

## Run locally

Just open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `franklin-13-week`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.
7. GitHub will give you a public website URL.

## Important

Progress is saved only in the browser/device you use. If you open the site on another device or clear browser storage, the checkmarks will not automatically follow you.
